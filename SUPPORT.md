# Replay Theater support

Replay Theater is maintained by Feida Wang. For questions, reproducible bugs or feature requests, use the [GitHub issue tracker](https://github.com/FeidaWang/Reply-Theatre/issues).

Include your package version, operating system, Python version, command used and the error message. For a viewer issue, explain the expected and observed behaviour. When possible, reproduce it with the bundled `skills/replay/examples/native-edits.json` example.

GitHub issues are public. Remove private chat IDs, absolute project paths, source code, access tokens and other personal information before posting. Do not attach a personal replay snapshot; use a small synthetic example instead. There is no paid support subscription or guaranteed response time.

This repository distributes the Skills-only local edition. It does not include automatic capture hooks or an MCP connection. The publisher does not operate a replay-processing server for this edition. OpenAI directory submission and account identity verification are separate from publishing this GitHub repository.

For data-handling information and privacy requests, read [PRIVACY.md](PRIVACY.md). The project's [terms of use](TERMS.md) explain the licence and supported scope. Start a privacy request with minimal information; this is a public issue tracker, not a private channel for sensitive information.
